# src/plugins/config

## Назначение

Плагин конфигурации декорирует Fastify валидированным объектом `AppConfig`.

## Что делает

- Принимает `config` через options.
- Выполняет `fastify.decorate("config", options.config)`.

## Зачем выделен отдельно

- Декуплирует загрузку env (`src/app/config.ts`) от потребителей.
- Позволяет тестам подменять конфиг без модификации глобальных переменных окружения.

## Контракт

После регистрации доступно `fastify.config` во всех следующих плагинах и модулях.

## Правила использования

- Любая новая env-настройка сначала добавляется в `AppConfig`, потом начинает читаться из плагинов/модулей через `fastify.config`.
- Не читать `process.env` напрямую в доменном коде.
