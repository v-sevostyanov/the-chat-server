# src/shared

## Назначение

`shared` содержит общие примитивы, переиспользуемые разными модулями без нарушения доменных границ.

## Подкаталоги

- `errors/` — базовые доменные/транспортные исключения (`AppError` и наследники).
- `http/` — общие схемы HTTP-ответов (например, унифицированный `ErrorResponseSchema`).
- `db/` — инфраструктурные helper-функции для ошибок БД.

## Правила использования

- В `shared` допускается только универсальная логика без привязки к конкретному модулю (`auth`, `messages`, `chats` и т.д.).
- Если код знает слишком много о конкретном бизнес-кейсе, ему место в соответствующем модуле.
- Из `shared` нельзя импортировать код из `modules/*`, чтобы избежать циклической зависимости.

## Что это даёт

- Единый формат ошибок в API и WebSocket.
- Повторно используемые guards для типичных low-level случаев (например, уникальные ограничения PostgreSQL).
- Меньше дублирования и меньше расхождений в поведении между модулями.
