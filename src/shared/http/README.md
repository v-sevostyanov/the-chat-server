# src/shared/http

## Назначение

Переиспользуемые TypeBox-схемы HTTP-контрактов, общие для нескольких модулей.

## Содержимое

- `schemas.ts` — `ErrorResponseSchema` (унифицированный error envelope).

## Конверт ошибки

Структура:

- `error.code: string`
- `error.message: string`
- `error.details?: unknown`

## Где используется

- В `*.schemas.ts` доменных модулей как базовая схема ошибок.
- В сочетании с `plugins/errors`, который приводит runtime-ошибки к этой форме.

## Практика изменений

- Изменения структуры `ErrorResponseSchema` считаются контрактно-значимыми и затрагивают все API-клиенты.
- При расширении схемы важно сохранить обратную совместимость для существующих клиентов и документации.
