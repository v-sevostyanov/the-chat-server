# AGENTS.md - src/shared/http

## Реальная ответственность директории

Общие TypeBox-схемы HTTP-контрактов для нескольких модулей.

Текущий ключевой контракт: `ErrorResponseSchema`.

## Что менять здесь уместно

- Развивать действительно общие HTTP envelope-схемы.
- Поддерживать единый формат ошибок.

## Что менять здесь неуместно

- Схемы конкретного домена (их место в `modules/<domain>/*.schemas.ts`).
- Runtime error handling.

## Границы зависимостей

- Допустимо: `@sinclair/typebox`.
- Недопустимо: зависимости на `modules/*` и `plugins/*`.

## Куда класть новый код

- В `schemas.ts` или соседний файл для общих схем.

## Связанные файлы

- `src/plugins/errors/errors.plugin.ts`
- `src/modules/*/*.schemas.ts`

## Локальный чеклист перед завершением

1. Схема нужна более чем одному модулю.
2. Изменение не ломает существующие потребители.
3. Backward compatibility общего envelope явно проверена при изменении публичного контракта.
4. `npm run typecheck`.

## Типичные ошибки будущего агента

- Добавить domain-specific схему в shared/http.
- Изменить общий error envelope без синхронного обновления модулей.
