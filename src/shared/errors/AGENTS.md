# AGENTS.md - src/shared/errors

## Реальная ответственность директории

Базовая модель прикладных ошибок:

- `AppError`;
- `BadRequestError`;
- `UnauthorizedError`;
- `NotFoundError`;
- `ConflictError`.

## Что менять здесь уместно

- Добавлять новые общие error-классы при реальной необходимости.
- Поддерживать стабильность `code` и `statusCode`.

## Что менять здесь неуместно

- Обработку Fastify ошибок (это `plugins/errors`).
- Ошибки, нужные только одному узкому use-case.

## Границы зависимостей

- Директория должна оставаться независимой от `modules/*` и `plugins/*`.

## Куда класть новый код

- В `app-error.ts` или соседний файл этой директории.

## Связанные файлы

- `src/plugins/errors/errors.plugin.ts`
- `src/plugins/websocket/ws-connection-handler.ts`

## Локальный чеклист перед завершением

1. `code` остается стабильным для клиентов.
2. `details` не содержит чувствительных данных.
3. `statusCode`, `code`, `message`, `details` остаются совместимым публичным контрактом.
4. Потребители не сломаны.
5. `npm run typecheck`, `npm run test`.

## Типичные ошибки будущего агента

- Переименовать `code` без обновления контрактов клиентов.
- Положить сюда доменную ошибку, которая не нужна за пределами одного модуля.
