# src/shared/errors

## Назначение

Единая модель прикладных ошибок для HTTP и WebSocket слоёв.

## Содержимое

- `app-error.ts`
  - `AppError` (базовый класс);
  - `BadRequestError` (`400`);
  - `UnauthorizedError` (`401`);
  - `NotFoundError` (`404`);
  - `ConflictError` (`409`).

## Контракт `AppError`

- `statusCode` — HTTP-статус.
- `code` — стабильный машинный код ошибки.
- `message` — человекочитаемое сообщение.
- `details?` — опциональные структурированные детали.

## Почему это важно

- `plugins/errors` использует эти классы для формирования стандартизированного error envelope.
- WebSocket слой (`ws-connection-handler`) извлекает `code`/`message` из `AppError`, сохраняя согласованную семантику ошибок между транспортами.

## Рекомендации

- Новые доменные ошибки оформлять наследниками `AppError`.
- `code` должен быть стабильным и пригодным для клиентской обработки.
- `details` включать только безопасные данные без утечки внутренней инфраструктурной информации.
