# src/shared/db

## Назначение

Общие low-level helpers для работы с БД-ошибками.

## Содержимое

- `errors.ts` — `isPgUniqueViolationError(error)`.

## Что делает helper

Функция определяет PostgreSQL unique violation (`SQLSTATE 23505`) в двух сценариях:

- код находится прямо в объекте ошибки (`error.code`);
- код вложен в `error.cause.code`.

## Зачем это нужно

- Сервисы могут единообразно маппить DB-ошибки в доменные `ConflictError`.
- Не нужно дублировать хрупкий парсинг структуры DB-ошибок в каждом модуле.

## Ограничения

- Helper покрывает только кейс уникальности.
- Для новых классов DB-ошибок нужно добавлять отдельные явные predicates, не перегружая существующую функцию.
