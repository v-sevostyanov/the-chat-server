# AGENTS.md - src/shared

## Реальная ответственность директории

`src/shared` хранит только общие примитивы для нескольких модулей:

- `shared/errors` - базовые прикладные ошибки;
- `shared/http` - общие HTTP-схемы;
- `shared/db` - low-level helpers для ошибок БД.

## Что менять здесь уместно

- Реально переиспользуемые компоненты без привязки к одному домену.
- Общие контрактные схемы и базовые error-классы.
- Код, который уже нужен нескольким модулям или явно является public cross-module contract.

## Что менять здесь неуместно

- Код, который нужен только одному модулю.
- Логику plugin lifecycle или transport routing.

## Границы зависимостей

- `shared/*` не должен импортировать `modules/*`.
- Избегать связей с конкретными plugins, если это не универсальный контракт.

## Куда класть новый код

- Ошибки: `shared/errors`.
- Общие TypeBox-схемы: `shared/http`.
- DB error predicates: `shared/db`.

## Связанные файлы

- `src/plugins/errors/errors.plugin.ts`
- `src/modules/*/*.schemas.ts`
- `src/modules/*/*.service.ts`

## Локальный чеклист перед завершением

1. Новый код действительно общедоменный.
2. Нет импорта из модулей.
3. `npm run typecheck`.

## Типичные ошибки будущего агента

- Выносить в `shared` частный код "на всякий случай".
- Ломать общий error envelope без синхронизации потребителей.
- Использовать `shared` как временную свалку для обхода границ модулей.
