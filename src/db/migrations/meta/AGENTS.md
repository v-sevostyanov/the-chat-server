# AGENTS.md - src/db/migrations/meta

## Реальная ответственность директории

Служебные метаданные Drizzle-мигратора (`_journal.json`).

## Что менять здесь уместно

- Только при осознанном recovery/выравнивании состояния мигратора.
- При ручном добавлении SQL-миграции `_journal.json` должен быть синхронизирован с именем, индексом и порядком миграции.
- Если используется Drizzle tooling для генерации, файл обычно меняется tooling-ом автоматически.

## Что менять здесь неуместно

- Ручные правки "для порядка", не связанные с мигратором.
- Добавление SQL или доменных файлов.

## Границы зависимостей

- Каталог изолирован от runtime-кода.

## Куда класть новый код

- Никуда, кроме служебных meta-файлов мигратора.

## Связанные файлы

- `src/db/migrations/*.sql`
- `drizzle.config.ts`

## Локальный чеклист перед завершением

1. Изменение meta действительно необходимо.
2. Порядок записей совпадает с порядком SQL-файлов.
3. `npm run db:migrate` проходит на реальной БД, если она доступна; иначе это ограничение явно названо.

## Типичные ошибки будущего агента

- Исправлять `_journal.json`, когда проблема на самом деле в SQL-миграции.
