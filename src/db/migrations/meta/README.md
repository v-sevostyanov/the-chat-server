# src/db/migrations/meta

## Назначение

Технические метаданные мигратора Drizzle.

## Содержимое

- `_journal.json` — журнал миграций (порядок, tag, timestamp, версия формата).

## Важные замечания

- Файл используется tooling-ом для согласования состояния миграций.
- Не использовать `_journal.json` как бизнес-источник данных.
- Ручные правки допустимы только при осознанном recovery-сценарии и после проверки на всех окружениях.

## Для аналитика

Журнал полезен для понимания хронологии изменений схемы, но сами DDL-детали и ограничения нужно смотреть в файлах `../*.sql`.
