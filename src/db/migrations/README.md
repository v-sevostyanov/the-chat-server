# src/db/migrations

## Назначение

Каталог хранит **пошаговые SQL-миграции** PostgreSQL для TheChat.
Это источник правды по тому, как схема БД эволюционировала во времени.

## Что уже отражено миграциями

- `0000_initial.sql` — базовые сущности чата: `users`, `chats`, `chat_members`, `messages`, enum `chat_type`, FK и индексы.
- `0001_auth_sessions.sql` — таблицы аутентификации: `user_credentials`, `auth_refresh_sessions`.
- `0002_direct_chat_uniqueness.sql` — поля direct-пары + уникальность прямого чата по `(direct_user_low, direct_user_high)`.
- `0003_users_last_seen.sql` — поле `users.last_seen_at` и индекс для presence.
- `0004_repair_users_last_seen.sql` — защитная idempotent-миграция восстановления `last_seen_at`.

## Практические правила

- Миграции должны быть **append-only**: не переписывать уже применённые файлы.
- Имена файлов держать последовательными (`000X_description.sql`) для предсказуемого порядка.
- Любое изменение индексов/ограничений должно иметь явную мотивацию в контексте read/write паттернов.

## Что проверять при изменении

- Корректность DDL на чистой БД и на БД после предыдущих миграций.
- Обратную совместимость с текущим кодом репозиториев.
- Риски блокировок при `ALTER TABLE` на больших данных.
- Наличие индексов под новые фильтры и сортировки.
