# AGENTS.md - src/db/migrations

Здесь хранится пошаговая история SQL-изменений PostgreSQL.

Правила:

- Любое изменение структуры БД добавляйте новой `000X_*.sql`.
- Не переписывайте старые примененные миграции без аварийной причины.
- Учитывайте backfill, nullable rollout, constraint validation и совместимость с тестовым мигратором.
- Имена индексов/constraints не должны конфликтовать.
- `_journal.json` в `meta` меняйте только для осознанного recovery/выравнивания Drizzle-мигратора; порядок записей должен совпадать с SQL-файлами.

Проверки: `npm run db:migrate` на реальной БД, если она доступна; иначе migration-backed tests и явное ограничение в финальном ответе.
