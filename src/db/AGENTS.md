# AGENTS.md - src/db

## Реальная ответственность директории

`src/db` - инфраструктурный слой PostgreSQL:

- клиент БД (`client.ts`);
- схема Drizzle (`schema/*`);
- SQL-миграции (`migrations/*`).

## Что менять здесь уместно

- Таблицы, индексы, enum и связи.
- Настройку DB клиента и readiness-check.
- Миграции структуры данных.

## Что менять здесь неуместно

- Доменные валидации и use-case правила.
- Формирование HTTP DTO.

## Границы зависимостей

- Допустимы `drizzle-orm`, `pg`, локальные schema exports.
- Недопустимы импорты из `modules/*`.

## Куда класть новый код

- Новая миграция: `migrations/000X_*.sql`.
- Новая таблица/enum: `schema/*.ts`.
- Логика подключения: `client.ts`.

## Связанные файлы

- `src/plugins/db/db.plugin.ts`
- `src/modules/*/*.repository.ts`

## Локальный чеклист перед завершением

1. Schema и SQL-миграция синхронизированы.
2. Нет schema-изменений без миграции.
3. При изменении структуры: `npm run db:migrate` на реальной БД, если она доступна.
4. Если реальная БД недоступна, запустить migration-backed тесты и явно указать это ограничение в финальном ответе.
5. `npm run typecheck`.

## Типичные ошибки будущего агента

- Редактировать старую миграцию вместо добавления новой.
- Изменить колонку в schema и забыть обновить SQL-миграцию.
