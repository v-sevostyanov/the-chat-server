# AGENTS.md - src/db

`src/db` - инфраструктурный слой PostgreSQL: `client.ts`, Drizzle schema и SQL-миграции.

Уместно менять таблицы, индексы, enum, связи, DB client и миграции. Не размещайте здесь доменные use-case правила, HTTP DTO или бизнес-валидацию.

Правила:

- `src/db` не импортирует `modules/*`.
- Любое schema-изменение требует синхронной SQL-миграции.
- Старые примененные миграции не переписывайте без аварийной причины.
- DB/query logic доменных сценариев держите в repository/data-access слое модуля.

Проверки: `npm run typecheck`; при изменении структуры БД - `npm run db:migrate` на реальной БД, если она доступна, иначе migration-backed tests и явное ограничение в финальном ответе.
