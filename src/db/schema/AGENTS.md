# AGENTS.md - src/db/schema

Здесь находится TypeScript-описание реальной PostgreSQL-схемы через Drizzle: таблицы, enum, индексы, связи и exports.

Правила:

- Schema должна соответствовать SQL-миграциям.
- При добавлении сущности обновляйте `index.ts`.
- Не размещайте здесь SQL-миграции или доменные бизнес-правила.
- Не импортируйте код из `modules/*`.

Проверки: `npm run typecheck`; для schema-изменений также проверяйте миграцию.
