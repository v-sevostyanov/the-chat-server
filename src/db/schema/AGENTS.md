# AGENTS.md - src/db/schema

## Реальная ответственность директории

TypeScript-описание реальной PostgreSQL-схемы через Drizzle:

- таблицы;
- enum;
- индексы и связи;
- общий экспорт схемы.

## Что менять здесь уместно

- Добавлять/изменять таблицы и поля, которые реально поддержаны миграциями.
- Поддерживать экспорт в `index.ts`.

## Что менять здесь неуместно

- SQL-миграции (их место в `../migrations`).
- Доменные бизнес-правила.

## Границы зависимостей

- Использовать `drizzle-orm/pg-core`, локальные schema-файлы и минимальные SQL primitives из `drizzle-orm`, когда они нужны для индексов/check constraints.
- Не импортировать код из `modules/*`.

## Куда класть новый код

- Новая таблица/enum: отдельный файл `*.ts`.
- Экспорт новой сущности: `index.ts`.

## Связанные файлы

- `src/db/client.ts`
- `src/db/migrations/*.sql`
- `src/modules/*/*.repository.ts`

## Локальный чеклист перед завершением

1. Schema соответствует SQL-миграции.
2. Nullability/длины типов не ломают текущие запросы.
3. Обновлен `index.ts` при добавлении новой сущности.
4. `npm run typecheck`.

## Типичные ошибки будущего агента

- Изменить schema без миграции.
- Добавить таблицу и забыть экспортировать ее через `index.ts`.
