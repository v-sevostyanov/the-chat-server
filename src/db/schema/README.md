# src/db/schema

## Назначение

Типизированная модель данных на Drizzle ORM.
Каталог описывает таблицы, enum-ы, связи и экспортирует их для репозиториев модулей.

## Файлы и ответственность

- `users.ts` — таблица пользователей, включая `last_seen_at`.
- `auth.ts` — `user_credentials` и `auth_refresh_sessions`.
- `chats.ts` — таблица чатов + enum `chat_type`.
- `chat-members.ts` — membership и роли участников чата.
- `messages.ts` — сообщения, индексы под историю/сортировку.
- `index.ts` — централизованный export схемы.

## Ключевые инварианты модели

- `users.username` уникален.
- Прямой чат фиксируется через `direct_user_low/direct_user_high`, уникальность обеспечена индексом в миграции.
- `chat_members` имеет составной PK `(chat_id, user_id)` и хранит роль участника.
- `messages.sender_id` не удаляется каскадно (`ON DELETE RESTRICT`) для защиты ссылочной целостности.
- `users.last_seen_at` служит durable-частью presence, в отличие от runtime-статуса в Redis.

## Потребители

- Репозитории модулей (`auth`, `users`, `chats`, `messages`, `presence`).
- `src/db/client.ts` создаёт `AppDb` на основе этого набора схем.

## Правила изменений

- Схему и миграции менять синхронно.
- Имена полей/таблиц согласовывать с текущими SQL-запросами в репозиториях.
- При добавлении колонки с бизнес-значением сразу продумывать:
  - индексирование;
  - влияние на сортировки;
  - nullability/значение по умолчанию;
  - API-контракты, которые читают это поле.
