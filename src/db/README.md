# src/db

## Назначение

`db` — единая зона для работы с PostgreSQL:

- создание типизированного клиента Drizzle;
- описание схемы таблиц и индексов;
- SQL-миграции как история эволюции данных.

Каталог не содержит доменной бизнес-логики.

## Состав

- `client.ts` — фабрика пула `pg`, инициализация Drizzle, health-check (`select 1`).
- `schema/` — декларативная схема таблиц/enum для TypeScript-слоя.
- `migrations/` — SQL-миграции, применяемые к реальной БД.

## Принципы

- Сначала обновляется схема и/или генератор миграций, затем миграция попадает в `migrations`.
- Репозитории модулей импортируют только `AppDb` и таблицы/поля из `schema`.
- Транзакционные границы задаются на уровне repository/service, а не на уровне `app`.

## Что важно для аналитики

- Инварианты целостности (`FK`, `UNIQUE`, `INDEX`) читаются из `migrations/*.sql`.
- Реальные payload-контракты API опираются на структуру именно этих таблиц.
- Поля времени (`created_at`, `updated_at`, `last_seen_at`) используются для сортировок, cursor-пагинации и presence-семантики.

## Риски и анти-паттерны

- Ручное редактирование старых миграций после применения в окружениях.
- Дублирование SQL-логики в разных модулях без общей причины.
- Обход repository-слоя прямыми SQL-вставками из handler/service.
